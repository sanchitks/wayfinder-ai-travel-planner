# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through GitHub instead:
**Security → Report a vulnerability** on this repository
(<https://github.com/sanchitks/wayfinder-ai-travel-planner/security/advisories/new>).

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply
within a few days, and a fix as soon as possible once the problem is confirmed. Please allow reasonable
time for the fix before telling anyone else.

## Scope

- The live demo, <https://sanchitks.github.io/wayfinder-ai-travel-planner/>, and its API on Render.
- The code in this repository.

Please test only with accounts you create yourself. Don't access other people's data, run denial-of-service
or high-volume automated tests, or use social engineering.

## What's in place

The [Security section of the README](README.md#security) describes how passwords, logins, Google sign-in,
the admin panel and the website itself are protected.
